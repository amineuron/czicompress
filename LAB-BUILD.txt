CziShrink 1.3.7-lab - custom Windows x64 laboratory build

Based on the tested CZI/HDF5/TIFF branch at b0a27c2. Includes copying other
files/folders and the November 9 worker, exception and CSV cleanup fixes.
ND2 processing is not included. This is a custom fork build, not a ZEISS release.

The build changes the version label and refreshes the integration harness lock
metadata for the existing Microsoft.DotNet.ILCompiler 8.0.33 dependency.
No scientific codec or package version is upgraded.

Rebuild with the SDK pinned in czishrink/global.json. From czishrink, prepare
the optional tools as documented in ScientificFormats/README.md, then run:

dotnet publish netczicompress.Desktop/netczicompress.Desktop.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:PublishReadyToRun=true -p:VersionSuffix=lab -o ../artifacts/lab-publish

Keep the complete published folder, FormatTools, notices and matching source
together. Dependencies retain their own licenses. Bundled notices are provided;
this build does not claim a new independent redistribution/legal audit.

Per-file decoded data/metadata verification does not establish byte-identical
container restoration or compatibility with every vendor-specific reader.
Linux/macOS codec packaging and vendor-reader checks remain separate work.
